# Street Rush

A 2D side-view arcade city-driving game built with Godot 4.7.2.

## First playable milestone
- Side-view arcade driving with responsive acceleration, braking and air control.
- Procedural-feeling city road scene with layered skyline, street lights and traffic props.
- Collectible coins, nitro pickups and simple hazards.
- Touch controls for Android and keyboard controls for desktop testing.
- HUD with speed, distance, coins and nitro.

The project is original and does not use assets or code from other games.
